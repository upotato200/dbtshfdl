# 달빛 윷마당

AI 없이 실제 플레이어 2–4명이 방 코드로 모여 즐기는 실시간 웹 윷놀이입니다.

## 주요 기능

- 6자리 초대 코드로 방 생성·입장
- 최소 2명, 전원 준비 시 자동 시작
- 서버에서 판정하는 도·개·걸·윷·모
- 말 업기, 상대 말 잡기, 추가 던지기, 4말 완주
- PC와 모바일 반응형 화면
- Cloudflare D1 기반 공유 게임 상태

## 로컬 실행

```bash
npm install
npm run dev
```

배포 빌드는 `npm run build`, 데이터베이스 마이그레이션 생성은
`npm run db:generate`로 실행합니다.
